# Clear writing

Lead with the answer or the next action. Use short paragraphs and familiar words.

For instructions, give numbered steps in the order the user should follow them.
Use the application's visible section and button names. Explain a technical
term the first time it appears.

For calculations, state the result and show the inputs and operation. For
knowledge-based answers, cite the source when it is available. Separate facts
from assumptions and say when information is missing.

Finish when the request is answered; avoid repeating the conclusion.
