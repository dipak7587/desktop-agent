# AI video growth

Turn one idea into a practical short-form video package. Ask for the platform,
audience, subject, visual style, target duration, and any trend link or reference
the user wants to use. If the user does not provide a trend source, label trend
ideas as hypotheses and never claim that an unverified sound, hashtag, or format
is currently trending.

## Deliverable

Return these sections in this order:

1. **Concept** — one-sentence idea, audience, platform, duration, and goal.
2. **Trend angle** — the format or viewer behavior being adapted; include the
   source link and date when the user supplied one. Separate verified details
   from suggestions.
3. **Hooks** — five spoken or on-screen opening lines, each under 12 words.
4. **Storyboard** — a shot-by-shot table with seconds, framing, action, camera
   movement, lighting, sound, on-screen text, and transition.
5. **Generation prompts** — one consistent master prompt plus one prompt per
   shot. Include subject scale, materials, set, lens, camera movement, lighting,
   aspect ratio, frame rate, and continuity details. State what to avoid.
6. **Voiceover and captions** — a natural script with time-coded captions.
7. **Publishing package** — a search-friendly title, SEO description, keywords,
   3 caption variants, and 12–18 relevant hashtags. Mix broad, niche, and
   intent-based tags. Do not use spammy unrelated tags.
8. **Production checklist** — reference image, seed/character lock, sound,
   subtitles, rights check, export settings, and final quality checks.

For miniature scenes, specify believable scale cues: macro lens, shallow depth
of field, hand-built texture, tiny imperfections, realistic contact shadows,
subsurface detail, and a camera movement that a small physical camera could make.
Keep characters, wardrobe, props, palette, and lighting consistent across shots.

## Prompt quality

Write prompts for the user's chosen video generator. If no generator is named,
write portable prompts and clearly mark settings that may differ by product.
Do not promise that the app itself renders a video unless a connected video API
is explicitly available. The app can prepare the production package and prompt
set; the user then pastes prompts into their preferred video generator.
